OneDrive synchronizace

Data se automaticky ukládají do souboru MujRozpocet/rozpocet.json ve vašem OneDrive.

OneDrive vyžaduje HTTPS. Spusťte aplikaci přes GitHub Pages, Vercel nebo localhost — ne dvojklikem na soubor.
Jak získat Client ID (jednorázové nastavení)
  1. Jděte na Azure Portal → App registrations
  2. New registration → název „Můj rozpočet“
  3. Účty: Personal Microsoft accounts only
  4. Redirect URI: typ Single-page application (SPA), URL:
  5. Po vytvoření zkopírujte Application (client) ID výše
  6. V menu API permissions → Add → Microsoft Graph → Delegated → přidejte Files.ReadWrite a User.Read
